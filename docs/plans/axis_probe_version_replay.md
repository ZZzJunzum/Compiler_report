# 第二个编译版本的复查

在完成主版本的首日发现后选用 JAX/jaxlib 0.8.2 的 Windows CPU 发行版。保留 Python 3.12.5、NumPy 2.3.5、SciPy 1.18.1、硬件、输入、单逻辑 CPU 亲和性、计时预算和混排规则。不同的编译器二进制分别留存 SHA-256。两个版本的结果独立汇总。

在读取第二版的生成代码和计时前，记录以下预测。

1. 在主仿射链上，全局联合计数返回标量对，计数循环没有外层分区。末轴联合计数返回两个行向量，其计数循环有外层分区。
2. 主图的轴交互为正，关闭任务分配后的差分 K 为负，两者各自超过同批次的交互 A/A 门槛。
3. 简化程序的大尺寸出现分区且 K 为负并超过门槛，小尺寸没有分区且 K 留在门槛内。

每种面板采集五个新进程。六张原图和两个简化尺寸全部保留，包括方向相反、未越过门槛以及语义不一致的结果。这个版本复查与主版本的跨日期要求分别计数。
