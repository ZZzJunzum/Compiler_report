# 已训练网络的范围检查

选用一个公开、可复现的手写数字分类任务。用 MNIST 官方训练划分的前 20,000 张图片训练一个四层隐藏层宽度均为 96 的 ReLU 网络。固定种子 4189、Adam 学习率 0.001、批大小 128 和 10 个完整 epoch 的预算。每个 epoch 丢弃不足一个批次的末尾。使用最终权重，报告完整官方测试集上的准确率。权重在性能实验前封存。

用官方测试划分顺序中的三个不重叠批次，每批 64 张。观测相邻隐藏层的两个线性输出，保留第二层的 ReLU 主输出。四层提供三个重叠片段，属于同一个网络。计时包含片段的两次矩阵乘法，输入已驻留设备，前缀推理在计时外完成。输出以同批完整网络导出的激活计算的 NumPy 计数和未观测片段为参照，另作同请求 S/J 直接核对。记录零邻域内的激活个数。

原版本上采用与轴实验相同的五进程、三个实际批次、混排别名、预热数、轮数和交互门槛。此项是探索性范围检查，报告各片段的性能方向与语义失败。三个片段不增加独立模型数量，不用于训练选择规则。

数据由 Yann LeCun 和 Corinna Cortes 提供。复现时按官方 SHA-256 下载，仓库保存模型参数、批次索引和测量。 [MNIST 数据说明](https://keras.io/api/datasets/mnist/) · [官方文件哈希](https://github.com/keras-team/keras/blob/v3.12.0/keras/src/datasets/mnist.py#L52-L60)
